📖 Panduan Memasang di PC Lain
  1. Pastikan PC tujuan sudah terpasang Node.js (minimal v18+).
  2. Clone repositori ini: git clone git@github.com:bayu-ngka/overlay-mlbb.git
  3. Buka folder project: cd overlay-mlbb/backend
  4. Install dependensi: npm install
  5. Jalankan server: node server.js
  6. Buka di browser: http://localhost:4000/control.html untuk Control Hub, dan pasang Browser Source di OBS dengan URL http://localhost:4000/bp1.html (Draft) & http://localhost:4000/sb1.html (Scoreboard).
